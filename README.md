# ResumeForge AI

> Build a resume that gets noticed.

ResumeForge AI is a modern AI-powered resume builder designed to help students, graduates, and professionals create ATS-friendly resumes, improve their content, optimize resumes for specific jobs, and export professional resumes.

## ✨ Features

- 🤖 AI-powered resume generation
- ✍️ AI summary and experience improvement
- 📊 ATS resume analysis
- 🎯 Job description matching
- 📄 Live resume preview
- 🎨 12 professional resume templates
- 🆓 3 free templates
- 🔒 Premium template system
- 💾 Resume saving and editing
- 📑 PDF export
- 📱 Fully responsive design
- ✨ Premium 3D interface and animations
